# 🖼️ CSP - 테마·배경 꾸미기

크랙의 테마·배경·글자·강조를 내 취향대로 꾸미는 사용자 스크립트입니다. **현재 버전: 4.4**

[설치 파일 열기](https://raw.githubusercontent.com/Ube-design/csp-theme/main/csp-theme.user.js) · [코드 보기](https://github.com/Ube-design/csp-theme/blob/main/csp-theme.user.js) · [문제 제보](https://github.com/Ube-design/csp-theme/issues)

## 설치 전 준비

이 파일은 단독 앱이 아닙니다. 사용자 스크립트를 실행하는 브라우저 확장프로그램이 필요합니다.
PC에서는 Tampermonkey 같은 사용자 스크립트 관리자를 사용할 수 있습니다. iPhone에서는 Safari용 사용자 스크립트 확장프로그램을 준비하고, iOS 설정의 Safari 확장프로그램 항목에서 활성화한 뒤 `crack.wrtn.ai` 실행 권한을 허용하세요. 메뉴 이름은 iOS와 확장프로그램에 따라 다릅니다.

스크립트 관리자에 따라 URL 설치, 파일 가져오기, 직접 붙여넣기 중 지원하는 방식이 다릅니다. 모든 확장프로그램에서의 호환성을 보장하지는 않습니다.

## 설치 방법

### 설치 링크를 지원하는 확장프로그램

1. 위의 **설치 파일 열기**를 누릅니다.
2. 확장프로그램의 설치 화면이 열리면 이름과 실행 사이트를 확인하고 설치합니다.
3. 크랙 페이지를 새로고침합니다.
4. 채팅방의 배경·테마 설정에서 원하는 테마를 선택합니다.

### 코드 화면만 열리거나 자동 설치가 안 되는 경우

1. 설치 파일을 다운로드하여 확장프로그램의 파일 가져오기 기능으로 불러오거나, 위의 **코드 보기 → Raw**에서 코드 전체를 복사합니다.
2. 확장프로그램에서 새 사용자 스크립트를 만들고 내용을 전체 붙여넣은 뒤 저장·활성화합니다.
3. `crack.wrtn.ai` 실행 권한을 허용하고 크랙 페이지를 새로고침합니다.

## 기존 수정본에서 옮기는 경우

기존 스크립트의 편집 화면에서 코드 전체를 이 배포본으로 교체하면 기존 스크립트 항목을 유지할 수 있습니다. 새 항목으로 설치했다면 기존 배포본은 꺼서 둘이 동시에 실행되지 않도록 하세요. 스크립트를 삭제하면 관리자의 저장 데이터도 지워질 수 있으므로 기존 항목부터 삭제하지 마세요.

사이트·브라우저·스크립트 관리자가 달라지면 설정 목록이 자동으로 이동하지 않을 수 있습니다.

## 주요 기능

- 테마·팔레트 선택 및 배경 이미지 꾸미기
- 테마 색상 자동 적용, 글자색·강조색 직접 설정
- 글씨 크기·코드블록 크기·폰트 두께·행간·자간·문단 간격 조절
- 사용자 웹폰트 등록·선택·삭제
- 이름을 붙인 테마 프리셋 저장·불러오기·삭제

## 색상과 초기화 동작

- **테마·팔레트 선택:** 선택한 테마 색상을 적용합니다.
- **테마 색상 자동 적용 켜기:** 현재 테마의 추천 색상으로 돌아갑니다.
- **직접 색상 선택:** 자동 적용이 꺼지고 선택한 색상을 사용합니다.
- **전체 초기화:** 현재 적용 중인 테마·글자 모양 등은 기본값으로 돌아가고 웹폰트 적용은 해제됩니다. **저장한 테마 프리셋 목록과 등록 웹폰트 목록은 유지됩니다.**
- 저장 목록에서 항목을 지우려면 각 목록의 삭제 기능을 사용하세요.

등록 웹폰트 목록은 폰트 소스와 글꼴 이름을 저장합니다. 폰트 제공 주소가 중단되거나 인터넷 연결이 없으면 해당 폰트가 표시되지 않을 수 있습니다.

## 업데이트

자동 업데이트를 지원하고 활성화한 관리자는 `csp-theme.meta.js`에서 새 버전을 확인하고 `csp-theme.user.js`를 내려받을 수 있습니다. 업데이트 지원 여부와 확인 주기는 관리자 설정에 따라 다릅니다. 직접 붙여넣기로 설치했다면 자동 업데이트 주소가 반영됐는지 확인하세요.

자동 업데이트가 지원되지 않으면 최신 설치 파일을 다시 가져오거나 기존 스크립트 내용을 전체 교체하고 새로고침하세요.

## 동작하지 않을 때

1. 확장프로그램과 스크립트가 모두 켜져 있는지 확인합니다.
2. `crack.wrtn.ai` 실행 권한을 확인합니다.
3. 다른 CSP 배경·테마 배포본을 꺼서 중복 실행을 피합니다.
4. 크랙 페이지를 새로고침합니다.
5. 계속 문제가 있으면 사용 기기·브라우저·스크립트 관리자·버전·재현 순서를 [Issues](https://github.com/Ube-design/csp-theme/issues)에 남겨주세요. 계정 정보와 개인 대화는 가려주세요.
